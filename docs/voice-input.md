# 声で発表を進める

公開URLの「同意して音声を開始」でブラウザのマイク許可を受け、操作する言葉だけを短く話す。開始前にはマイクも認識サービスも起動しない。準備前なら発表も同時に開始する。

| 発話 | 動作 |
|---|---|
| 次へ／前へ | 工程を1つ進める／戻す |
| 取り消し | 直前の操作を1回戻す |
| 1枚目へ／2枚目へ／3枚目へ → 確認 | 候補を出して確認後に寄り道する |
| キャンセル | 寄り道の候補を取り下げる |
| 続きへ | 寄り道前の工程・検索語・結果・選択に復帰する |
| 停止 | 発表・音声・カメラを停止する |

「相棒、次へ」のような呼びかけ、末尾の句読点にも対応する。説明文「次へと言います」や否定文は操作しない。音声での検索・開始・リセットは対象外。「音声を停止」ボタンは音声入力だけを止める。別タブに移ると音声とカメラを止め、戻っても自動再開しない。

## 実装とデータの扱い

`src/input/speech.js` が `SpeechRecognition` / `webkitSpeechRecognition` の日本語認識を使い、確定した文字を限定されたコマンドへ変換する。`src/main.js` → `src/state/presentation.js` の既存状態処理へ `source: voice` のイベントを渡す。`src/ui/speech-panel.js` が状態と聞き取った言葉を表示する。

- 途中の認識結果は画面表示だけ。同じ認識器内の結果再送・追加の確定結果を抑える。
- コマンド1つにつき認識器を区切り（`continuous=false`）、認識器の開始時の発表セッションと版を固定する。途中で画面が変わった結果は実行しない。「停止」は同じ発表セッション内なら現在の版で受け付け、前の発表セッションからは受け付けない。
- 認識器ごとに最初の未処理の確定結果だけを判定し、同じ認識器の残りは実行しない。確定結果または不一致の後にその認識器が終了すると、新しい認識器で次のコマンドを待つ。各コマンドの前の`speechstart`は前提にしない。「3枚目へ」と「確認」は別の認識区間に分けて話す。
- 停止・終了・認識エラー・再開始の後に届いた古い結果は実行しない。確定結果のない予期しない終了・エラー・停止の後は自動再開せず、本人のボタン操作で再開する。
- カメラ判定はOpenAI Decisions API。音声認識はブラウザ提供元の機能であり、このアプリのOpenAIキーを使わない。音声が提供元の認識サービスへ送られる場合がある。アプリは音声を保存せず、認識文字は表示用メモリにのみ保持する。
- 非対応、マイク拒否、機器なし、ネットワーク不良、無音、日本語非対応を案内し、文字入力・ボタンを残す。日本語パックは自動インストールしない。

ブラウザ対応・ネットワーク要件は [MDN SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)、停止の意味は [abort()](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/abort) を参照。

## 検証

2026-10-18、PR #22と既存のSTOP条件を合わせたPR #24の候補で、`npm test`はビルドと開発/静的HTTP検査を含む全87件、うち音声15件が成功した。speechstartを合成しない複数コマンド、説明後の受付、不一致後の再受付、古い認識器の遅延結果、同じ結果の再送、1認識器による寄り道提示と確認の同時実行拒否、同じ発表セッション内の版変更後STOP、前のセッションのSTOP拒否を確認した。

1280×720と390×844の実ブラウザでは、合成映像・模擬音声・模擬APIによる16状態が成功。「説明→次へ→次へ→前へ」、nomatch後の次の操作、カメラとの排他切替、設定を閉じたままのエラー表示、明示的な手動切替、別の認識区間での寄り道確認と復帰、停止後に認識が自動再開しないことを確認した。JSエラー・ネットワーク失敗・外部通信・横溢れは0。PCでは発表中の台本と進行・終了操作が720px高の画面内に収まった。

ローカルの音声検証ページは `npm run build && node scripts/speech-browser-fixture.mjs` で生成し、プレビューの `/_speech-check.html` と `/_speech-unsupported.html` を開く。模擬認識器は確定結果の後にendを発火し、重複結果は前の認識器へ再送する。生成ページは検証専用で、配備ファイルに含めない。

**未検証**：本人の実マイク、各ブラウザの実認識サービスのイベント列、会場の雑音・発音・ネットワークによる精度と遅延。模擬入力の成功を音声認識精度と扱わない。
