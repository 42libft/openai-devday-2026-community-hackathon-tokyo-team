# PDF・PPTXを使った発表

## 利用手順

1. 発表開始前の「スライドファイル」でPDFまたはPPTXを選ぶ。25MB以下・1〜100ページに対応。
2. 読み込み完了後、先頭ページとページ数を確認して開始ボタンを押す。
3. 「次へ」「前へ」または矢印キーで進行する。カメラ・音声も同じページ数で動作する。音声の「8枚目へ」→別発話で「確認」のように、読み込んだ範囲内のページへ寄り道できる。
4. 寄り道先から「続きへ戻る」で元のページへ戻る。最後のページでは「次へ」は無効になる。
5. ファイルを変更するには「発表を終了」→「はじめから」で準備へ戻って選び直す。「サンプル台本に戻す」で、同じブラウザに保存した3工程の台本へ戻せる。

発表者ノートは抽出しない。ファイルはブラウザ内だけで処理し、サーバーやOpenAIへ送信・保存しない。再読み込みするとファイルと発表状態は失われる。サンプル台本の編集内容は従来どおりブラウザ保存される。

## 失敗からの復旧

- 形式違い・空ファイル・25MB超過・100ページ超過・破損・パスワード保護は読み込みを適用せず、現在のスライドを保持する。保護を解除するか、PDFへ書き出して選び直す。
- 読み込み中の「読み込みをキャンセル」は結果の適用を取りやめる。連続で選び直した場合も、最後に選んだファイルだけが反映される。
- 読み込み中は発表を開始できない。カメラ・音声開始も読み込み完了まで待つ。
- 特定ページの描画に失敗すると「表示を再試行」が現れる。再試行するか別ページへ移動できる。遅れて完了した古いページ描画は現在の表示を上書きしない。

## 対応範囲と実装

- PDFは[Mozilla PDF.js](https://github.com/mozilla/pdf.js)でcanvasへ描画する。PPTXは[@aiden0z/pptx-renderer](https://github.com/aiden0z/pptx-renderer)で表示する。両方とも必要なときにだけ遅延読み込みする。PDF workerもアプリと同じ配布物に含む。
- PPTXは静止スライドのプレビュー。アニメーション・動画の再生やPowerPointと完全に同じレイアウトは保証しない。フォント・SmartArt等の違いが気になる場合はPDFを使う。旧PPT・KEYは直接対応しない。
- PPTXの外部参照を除去してから描画し、ZIPの展開サイズ・ファイル数にも上限を設ける。PPTXの展開後データが96MB、メディアが64MBを超える場合は読み込めない。
- `src/slides/deck.js`: 形式判定、PDF/PPTX読込・描画・解放。
- `src/slides/upload.js`: ファイル上限、キャンセル・競合、描画完了の競合制御。
- `src/ui/deck-upload.js`: 選択・進行・復旧表示。
- `src/state/presentation.js`: 実ページ数に基づく進行・寄り道・復帰。ファイル変更時にセッションを更新して古い操作を拒否。
- `src/input/manual.js` / `speech.js`: 実ページ数に応じた「N枚目へ」。サンプル台本は3枚、アップロード時は最大100枚。
