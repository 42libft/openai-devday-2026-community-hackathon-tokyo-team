## ブラウザ検証の再現

Google Chromeを使います。通常の利用者プロファイルや既存タブは使用しません。

```sh
npm test
npm run preview -- --host 127.0.0.1 --port 4208 --strictPort
```

別terminalで次を実行します。

```sh
APP_URL=http://127.0.0.1:4208/ node scripts/browser-check.mjs
```

macOSの標準インストール以外では `CHROME_BIN` にChrome実行ファイルを指定してください。証拠は既定で一時フォルダに出力され、出力先は最後のJSONに表示されます。`EVIDENCE_DIR` で変更できます。元の実行では4枚のPNGと `browser-result.json` を保存しました。
